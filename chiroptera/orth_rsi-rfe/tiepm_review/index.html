What tiePM means, and the question

Each alignment has three rows: the rsi window, the rfe window and the reference consensus. Both flanks match, so the two windows are the same place in the two genomes. The pipeline first asks whether it is a SINE present in both (the two copies at least 65 % identical to each other and enough identical bases with the reference); these alignments failed that test. It then asks which genome has the insertion, by counting each row's residues in the SINE columns: a row carries the copy if it has ≥ 50 % of the reference's residues there. Here both the rsi and the rfe rows do (306 of 306; in the other 0 neither does), so the rule cannot say PM or MP, and the locus is rejected as tiePM. The question for you: is this a SINE present in both genomes, only diverged? If yes, these loci would become SINE (present in both) instead of being rejected.
