Main flank-mapping rows only (clusters C…); rescue (M) and nested (N) rows are left out, so a locus a run holds as an M row counts as missing from that run. Check: each input copy ±10 kb was aligned to the other genome (minimap2 -x asm20) and its junction lifted; agree = the row's partner is within 50 bp of the lifted junction. Disagree is not the same as wrong: at segmental duplications the check itself can pick the wrong copy. Before the junction fix (SINE_orth_loc 41ccc90) about 5 % of anchors lay more than 50 bp off the window junction, because a reference longer than its copy (partial copy, composite) can start anywhere in the left flank; the comparison then uses the window position. With the fix the junction is the annotated copy's own start: 1.6 % remain off, and 198 more rows become testable.

Loci that differ between runs

Pick a group, then open a run's alignment for a locus. The alignment opens in the SINE loci browser in a new tab, one tab per run, so the same locus can be compared side by side. A name starting with ~ means that run has no main row at the locus; it is the alignment the run made there instead (an M rescue row, or one rejected, e.g. shortRF / badRF).

  • disagree: a run's row differs from the copy +-10 kb alignment check
