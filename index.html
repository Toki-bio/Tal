Erinaceidae SINE — confirmed, but not Talpidae

Erinaceus europaeus (European hedgehog) belongs to Erinaceidae, a different Eulipotyphla family from the 6 Talpidae species above — kept on this site for infrastructure reuse, not because it is a Talpidae result. Unlike the scorpion work below, this SINE family is a real, confirmed classification against known literature consensuses (ERI-1/ERI-2, Borodulina 2001), not a de novo/unconfirmed candidate.

Scorpiones — unconfirmed candidate SINE-like elements (not Eulipotyphla)

These are not confirmed SINEs. Unlike every species above (Talpidae and the confirmed Erinaceidae/eri result), scorpions have no known SINE consensus library to classify against — the 29 "subfamilies" below are candidate consensuses from an exploratory de novo discovery pipeline (cross-species fragment homology search, manual SubFam clustering), not validated SINE families. Kept in this repo purely for infrastructure reuse, in a completely unrelated taxon (an arachnid, not a mammal). See sco/LOG.md for the full methodology (why scorpions, de novo query construction, batch genome scan across 11 assemblies, and the manual SubFam clustering that produced the 29 candidate consensuses below).

Timema cristinae — unconfirmed candidate SINE-like elements (not Eulipotyphla)

These are not confirmed SINEs. Same situation as the scorpion work above: Timema cristinae (a stick insect, Phasmatodea — an insect, unrelated to the scorpion work too) has no known SINE consensus library, so the 8 "subfamilies" below are candidate consensuses from an exploratory de novo discovery pipeline (cross-species fragment homology search against the same 958-fragment query bank used for scorpions, then manual SubFam clustering), not validated SINE families. Kept in this repo purely for infrastructure reuse. See tim/LOG.md for the full methodology.
